# Robin Swarm Engine

The Robin Swarm Engine is an internal component of the Robin Institutional Trading Platform. 
It uses swarm intelligence to predict and simulate market sentiment, social dynamics, and multi-agent interactions to inform trading decisions.

## Architecture
- **Backend:** Python / FastAPI / LangChain (Port 5001)
- **Frontend:** Node.js / React (Port 3001)
